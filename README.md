# Hospital Queue Management System

An intelligent hospital queue management system designed to optimize patient wait times and streamline doctor scheduling.

## Purpose

The Hospital Queue Management System helps hospitals efficiently manage patient queues by:
- Providing real-time visibility into doctor availability and patient wait times
- Intelligently recommending the best doctor based on queue lengths and specialty matching
- Reducing patient wait times through data-driven queue optimization
- Displaying queue analytics and heatmaps for hospital operations

## Features

### 📊 **Dashboard**
- Real-time overview of all doctors and their current queue status
- Visual display of wait times and patient counts
- Key metrics and statistics at a glance

### 👨‍⚕️ **Doctor Management**
- Browse all available doctors with specialties
- View current queue status for each doctor
- See estimated wait times
- Doctor card interface for easy queue comparison

### 🎫 **Personal Queue**
- Check your position in the queue
- View estimated wait time for your appointment
- See time savings compared to alternative doctors
- Real-time queue position updates

### 🗺️ **Heatmap**
- Visual representation of queue distributions across doctors
- Identify peak hours and busy periods
- Color-coded intensity map for easy interpretation

### 🔔 **Alerts**
- Real-time notifications for important events
- Queue status changes
- Estimated wait time updates
- Priority warnings

### 🤖 **Smart Suggestion Engine**
- Intelligent algorithm to find the best available doctor
- Considers queue lengths and wait times
- Automatic recommendations to reduce wait times

## Tech Stack

- **Frontend:** React 19.2.5
- **Build Tool:** Vite
- **Styling:** CSS
- **State Management:** React Hooks (useState)
